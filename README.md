# 🎥 LetterBotd — Core Film Intelligence Engine

Project Overview
This project is a functional chatbot built for movie lovers. The chatbot takes what a user types, understands what information they are looking for, and pulls real-time movie details from a live online database to show the results instantly on the screen.

Features
Chatbot Replies: The chatbot responds naturally to user-typed text or button clicks.

Suggested Option Chips: Quick, clickable buttons that appear inside the chat to help the user ask follow-up questions easily.

Quick Hello and Goodbye Buttons: Dedicated buttons that instantly trigger greetings or sign-offs without breaking the movie search logic.

Dashboard Layout: A structured design showing new releases on the side, the chat in the middle, and extra details like movie posters on the right.

Conversational Intents Covered
The chatbot is programmed to handle several different types of conversation topics automatically:

Cast Details: Shows the main actors in a movie and the characters they play.

Director Information: Identifies the filmmaker who directed the selected movie.

Story Overview: Gives a quick plot summary or synopsis of the film.

User Ratings: Displays the current voting scores and review counts from global users.

Financial Stats: Shows the production budget and total box office earnings.

Written Reviews: Pulls real feedback comments written by viewers.

Movie Recommendations: Suggests similar movies you might enjoy based on your current search and automatically highlights them as clickable links.

Built Using
HTML: Used to create the text, boxes, sidebars, and basic structure of the website.

CSS: Used to style the interface with a premium dark theme and smooth layouts.

JavaScript: Used to handle the chatbot logic, read user input, and fetch data from the live Movie Database API.
